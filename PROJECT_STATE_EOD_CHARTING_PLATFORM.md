## Unresolved findings

1. **Worker-cap contract versus implementation:** [AGENTS — Repo boundaries](AGENTS.md#repo-boundaries) states Bhavcopy binary worker cap **4**. The supplied [ingestion.rs](src-tauri-shell/src/bhavcopy/ingestion.rs) declares `MAX_BHAVCOPY_BINARY_WORKERS = 2` and `MAX_BHAVCOPY_PREFILTER_WORKERS = 4`; [bhavcopy_recovery.rs](src-tauri-shell/src/bhavcopy_recovery.rs) declares `MAX_BUFFERED_CHECKPOINT_WORKERS = 2`. Whether “cap 4” means a permitted upper bound or an expected runtime count needs explicit reconciliation. **No source change authorized or made.**
2. **Storage-mode distinction (not a proven defect):** the normal UI Create Database flow explicitly passes `binary` ([databaseLifecycleService.ts](src/features/workspace/databaseLifecycleService.ts), [connection_registry.rs](src-tauri-shell/src/database/connection_registry.rs)), while [bootstrap.rs](src-tauri-shell/src/database/bootstrap.rs) and [storage_mode.rs](src-tauri-shell/src/database/storage_mode.rs) default to `hybrid` absent an explicit selection. Native new-database and reopened legacy-database behavior was not executed.
3. **Historical BSE completeness is not established:** BSE import, name-history and chart identity code exists ([bse_identity_imports.rs](src-tauri-shell/src/database/bse_identity_imports.rs), [name_history.rs](src-tauri-shell/src/database/bse_identity_imports/name_history.rs), [eod_data/bse_code_history.rs](src-tauri-shell/src/database/eod_data/bse_code_history.rs)), but the included [JSON](docs/changes/2026-10-30-bse-name-history/native-proof-1793303233854903400/official-name-history.json) is test fixture material, **not a production database or all-symbol certification**. No live BSE price or metadata database was included for comparison.
4. **Official provider and corporate-action acceptance is unproven:** preview/apply and approval handlers and tests are present, but there is no authorized live download/session, populated database or native checkpoint in the source ZIP to prove all identity transitions, pending jobs or financial approvals work end-to-end ([corporate_action_imports.rs](src-tauri-shell/src/database/corporate_action_imports.rs), [DatabaseToolsDialogs.tsx](src/components/DatabaseToolsDialogs.tsx)).
5. **External plugin limitation:** [pluginLoader.ts](src/plugins/pluginLoader.ts) explicitly registers external plugin metadata without enabling external code execution. This is a documented implementation constraint, **not** proof of a broken integration.
