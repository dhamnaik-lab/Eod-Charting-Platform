# Corporate Action Phase 1 Current-State Audit V1.10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run a standalone, zero-write Corporate Action Phase 1 V1.10 audit that measures the exact current Split/Bonus state, reconciles the V1.9/V1.9.1.1/V1.9.2 historical cohorts, summarizes every Corporate Action type, and proves the live SQLite family was unchanged.

**Architecture:** The audit package is external to production source. A PowerShell wrapper establishes a quiescent/live-hash boundary and creates a private SQLite-family snapshot; a standard-library Python audit opens only that private snapshot using SQLite read-only URI mode plus `PRAGMA query_only = ON`, validates the schema, classifies current rows, reconciles locked historical cohorts, writes deterministic TXT/CSV/JSON reports, and finally re-verifies the live DB/WAL/SHM hashes. Before implementation, a source-contract extraction gate maps every classifier to existing production state/rules; if faithful classification requires unavailable production runtime logic, execution stops for redesign instead of duplicating semantics by guesswork.

**Tech Stack:** PowerShell 7.6.x, Python 3 standard library (`sqlite3`, `csv`, `json`, `hashlib`, `unittest`, `pathlib`), SQLite read-only URI mode, SHA-256 manifests. No React/Vite/Tauri/Cargo/npm operation is part of the live audit.

- [ ] **Step 3: Implement minimal read-only open**

```python
def open_read_only_snapshot(path: Path) -> sqlite3.Connection:
    uri = f"file:{path.as_posix()}?mode=ro"
    conn = sqlite3.connect(uri, uri=True)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA query_only = ON")
    if conn.execute("PRAGMA query_only").fetchone()[0] != 1:
        conn.close()
        raise RuntimeError("PRAGMA query_only enforcement failed")
    return conn
```

- [ ] **Step 5: Implement PowerShell live-family hash capture**

Use a function returning an array-safe object rather than relying on collection `.Count` properties:

```powershell
function Get-SqliteFamilyState {
    param([Parameter(Mandatory=$true)][string]$DatabasePath)
    $paths = @($DatabasePath, "$DatabasePath-wal", "$DatabasePath-shm")
    @($paths | ForEach-Object {
        if (Test-Path -LiteralPath $_) {
            [pscustomobject]@{
                Path = $_
                Exists = $true
                Length = (Get-Item -LiteralPath $_).Length
                SHA256 = (Get-FileHash -LiteralPath $_ -Algorithm SHA256).Hash
            }
        } else {
            [pscustomobject]@{
                Path = $_
                Exists = $false
                Length = 0
                SHA256 = $null
            }
        }
    })
}
```
