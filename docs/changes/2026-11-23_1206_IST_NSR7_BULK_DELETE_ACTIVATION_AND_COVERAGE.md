## Database activation and Manual Import

Explicit create/open and saved-selection startup restore prepare the schema under the per-database lease with durable intent. Preparation finishes before publishing or caching a newly selected database. The registry revision is rechecked before publishing, and the registry lock is released while preparation takes the canonical lease. A saved preparation failure is logged and leaves the prior registered selection available for explicit reopen. Ordinary writable opens configure the connection without migrations. The stats cache miss uses a read-only connection and never stores that connection as the writable cache entry. An error or unresolved conflict retains its intent. Successful completion clears only the current attempt after the owning operation's existing recovery bookkeeping. Quote and schema markers use the same journal, with old database-wide interruption handling preserved.
