Current chart engine already has base/overlay canvases, dirty rendering and basic conflation. Extend the shared contracts; do not rewrite working charts. Rust data services preserve full-resolution authoritative data; display LOD must never alter stored values or backtest inputs. Keep financial precision separate from GPU Float32 coordinates.

Windows system WebView2, macOS WKWebView, Linux WebKitGTK by default. Common source does not mean common binary. Fixed WebView2 optional only on Windows, with security updates managed by distributor. Do not bundle a browser by default. No mandatory Rust/Node/Go/Python end-user installation.

4. Non-negotiable rules

  • Zero new dependencies by default. Every exception requires explicit approval, exact version/features, alternatives, target graph and artifact delta, measured benefit, licensing/security/maintenance and compatibility assessment.
  • Preserve working EOD behavior, EOD1 format, SQLite integrity, chart geometry, CA explicit approval and raw-data immutability, quote-only deletion, exchange symbol identity, special-session calendar and recovery gates. Bhavcopy cap 4; preserve journal-governed durability contract. Unsupported writes/deletion fail closed.
  • Use scoped branches/PRs; preserve dirty work; follow AGENTS.md backup policy with scripts/create-project-backup.ps1 before edits. Update relevant HANDOFF.md and NEXT_THREAD_PROMPT_EOD_CHARTING_PLATFORM.md when project state changes. Current architecture document describes implemented reality only.
  • BUILD-01: reuse root shared target. On Windows use scripts/Invoke-EOD-SharedCargo.ps1 Preview then approved Run for routine compilation. Serial checks; canonical real rustfmt --edition 2021 --check on changed Rust before publication. No nested tmp Cargo target, release, installer or portable staging without explicit approval.
  • TMP-01: fixtures under tmp/fixtures/<task>, evidence under tmp, final evidence ZIP in $HOME\Downloads with IST timestamp and SHA-256. Never automatically delete shared targets, databases, backups or unmarked scratch. No production destructive fixtures.
  • No OpenAI API integration, mass dependency upgrades, unrelated refactors, or automatic merges. Keep renderer calls behind src/platform/*.
